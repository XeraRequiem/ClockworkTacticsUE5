# ClockworkTacticsUE5
UE5 Hex-based Strategy Game

I've always loved both Roguelike and Tower Defense games. I've only ever seen the two combined once as a mini game in Arknights. So, I decided to make it myself! Clockwork Tactics is a roguelike Hex-based Tower Defense game with a Steampunk finish. I'm developing this game as a solo project to expand my knowledge of the Unreal Engine, learn and implement new technologies, and just build something I love.
